Main project · in daily use

The order-to-Tally system for a paper trader

One system takes an order from a customer's message to the mill, reads the mill's bill when it comes back, books both sides in Tally and tracks the payment.

Problem
Orders arrived as WhatsApp messages, bills as PDFs from 30+ mills, and staff typed all of it into Tally by hand.
Built
A Django order system, mill POs sent as PDFs, an invoice reader, an office agent that books purchase and sales bills, and a due list by payment terms.
Result
400+ bills a week now go into Tally without typing, used daily across two offices, with 3,500+ tests run before every change.

Engine · Python

An invoice reader that checks its own work

Every paper mill prints its bill differently. This engine reads them all and fills each bill onto the right order.

Problem
One parser per mill broke quietly whenever a mill changed its layout, and bills were filled short without anyone seeing.
Built
One engine that reads by labels, columns and totals. A reading is used only when it adds up to the bill's printed total. Odd PDFs go to a local AI model on the firm's own server, and its answer must pass the same check.
Result
Before launch it re-read every bill since June and made no wrong fill. It now runs every 15 minutes on its own.
  • Python
  • PDF parsing
  • Tesseract OCR
  • Ollama
  • Gmail API

How I work

Start with the person, end with the numbers.

The same five steps on every project, from a client's website to the firm's Tally books.

  1. 01

    Sit with the person doing it

    Watch the job done by hand, with the real files and messages.

  2. 02

    Copy their way of working

    The software follows their steps, so nobody has to learn a new routine.

  3. 03

    Build small, on real data

    One working piece first, tried on last month's actual records.

  4. 04

    Check it against their numbers

    Totals must match what they already trust before anything goes live.

  5. 05

    Keep it running

    Backups, tests and fixes after launch. I build with AI coding tools and own what ships.
